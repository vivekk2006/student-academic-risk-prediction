# Student Academic Risk Prediction

## Project Overview

This project is about using machine learning to predict student academic outcomes and identify students who may be at risk of dropping out.

The project uses the UCI Predict Students' Dropout and Academic Success dataset. Different machine learning algorithms will be studied and compared to find an approach that is suitable for this type of student data.

## Project Objectives

- Understand the factors related to student academic outcomes.
- Study and prepare the student dataset.
- Explore different machine learning algorithms.
- Compare the performance and limitations of the selected algorithms.
- Evaluate the models using suitable performance measures.
- Build a clean and organized Python implementation.
- Explore how machine learning can support an early-warning system for students who may need academic support.

## Target Outcomes

The model will predict one of three possible student outcomes:

- Dropout
- Enrolled
- Graduate

## Algorithms

The following algorithms will initially be studied and compared:

- Logistic Regression
- Decision Tree
- Random Forest

The final model will be selected after testing and comparing the algorithms. No algorithm is being treated as the final model at this stage.

## Dataset

The project uses the following dataset:

**UCI Machine Learning Repository – Predict Students' Dropout and Academic Success**

The dataset contains information related to students' academic, demographic, socioeconomic, and enrollment characteristics.
